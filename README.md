# Coaching Centre WordPress Theme & Plugin

A modern, responsive, and lightweight WordPress theme and companion plugin tailored for Bangladeshi coaching centres and academic care institutions (জ্ঞানদীপ একাডেমিক কেয়ার).

## Key Features

- **Responsive & Modern Design**:
  - Clean Bangla typography (`Hind Siliguri`, `Noto Sans Bengali`).
  - Dark mode & light mode toggle support.
  - Mobile-first responsive navigation and layout.
- **Academic & Course Management**:
  - Custom post types for Courses (`cc_course`), Teachers (`cc_teacher`), Testimonials (`cc_testimonial`), FAQs (`cc_faq`), Admission Applications (`cc_registration`), and Contact Messages (`cc_message`).
  - Weekly model test / exam registration system.
  - Online student admission application form (`/registration/`).
  - Interactive FAQ accordion and testimonials slider/grid.
- **Admin Dashboard**:
  - Dedicated admin settings page to manage branding, contact details, branch list, social links, and notices.
  - Secure Meta Box integration for course metadata, teacher details, and application data.

## Project Structure

- `wp-content/themes/coaching-centre/`: Primary WordPress theme.
- `wp-content/plugins/website-manager/`: Custom companion plugin managing post types, taxonomies, and custom fields.

## Requirements

- WordPress 6.0+
- PHP 7.4+
- Meta Box plugin (for custom field metaboxes)
